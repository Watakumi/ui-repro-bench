## judge の傾向

- 「Search が広い」「Notifications が狭い」「Go to file が狭い」は幅が外れ。ずれの原因は隣の Sign up・Star・Code ボタン
- 「緑のステータス点」は2つ目のアバターの誤読
- 「アバターは画像ソースがないので減点しない」を鵜呑みにしない（identicon は描ける）
- 座標（「1127 でなく 1095」）は縮小表示の値
- 最新コミット行のハッシュの位置は、方向を逆に書くことがある（12-09-04）
- 「タブの間を広げよ」は 15-41-44 では誤診（タブ間は一致、不足はラベル→数字と Counter の幅）、15-58-08 では正しい（数字→次のアイコン 49、参照 66）。どちらかは塊の表で決める

- 「…」ボタンが「濃い、淡い灰色にせよ」は誤り（16-04-08。参照の地 `#59636e` のほうが暗い）。参照は暗い地に白い点
